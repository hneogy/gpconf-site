How this page gets its data

  • /api/activity is a Cloudflare Pages Function. On a cache miss it makes seven GitHub REST calls (two issues, two pull requests, the corpus's latest release, and the two repositories), keeps state, dates, counts and links, and stores the result at the edge for one hour; visitors are served the cached copy, so GitHub sees about one refresh per hour per edge location.
  • If GitHub fails, the last good copy (kept for 30 days) is served with its original timestamp and a “stale” note; if none exists the page shows the static links only.
  • Requests are authenticated with a read-only, public-repositories token stored as a Cloudflare secret; the token never appears in a response. No titles, bodies or comment text are read or shown.
