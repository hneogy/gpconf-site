The satellite catalog passed 99,999. Does your software know?

On 11 July 2026 the satellite catalog reached number 100000, and much older software can quietly lose every satellite catalogued since. gpconf is a free test kit of eighteen cases, built from real catalog data, that shows where a program goes wrong. Below is what it found in eight libraries, each finding reported to the library’s makers.

Since 2026-07-11 the catalog has numbers above 99999. gpconf is a conformance corpus for TLE and OMM parsers at the five-digit boundary. It has eighteen cases, covering Alpha-5 TLEs, six- and nine-digit NORAD_CAT_ID, and OMM in CSV, JSON, XML and KVN. Every expected value traces to a recorded URL, retrieval time and SHA-256.

pip install gpconf
gpconf fetch
gpconf run --preset reference

The fetch runs once: about 60 requests to CelesTrak, cached. Then name your library’s preset (sgp4, pyephem, satellite.js, tle.js) or point the runner at your own parser.
